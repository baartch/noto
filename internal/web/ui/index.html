Yes, generally you need to rebuild it. The index stores numerical representations—embeddings—of your memories. A model creates those numbers so that related text lands close together in its particular mathematical space.

When you search, the app turns your question into a vector and compares it with the stored vectors. That comparison only makes sense when the question and memories were embedded using compatible models.

Think of it like coordinates on a map: two maps can both use pairs of numbers, but the same coordinates don’t necessarily point to the same place. Likewise, two models may produce vectors of the same length, but their meanings can differ. Some models also produce vectors of different lengths, which can make comparison impossible altogether.

Changing models therefore usually means:

  1. Keep the original memories.
  2. Generate new embeddings for each memory using the new model.
  3. Build a new index from those embeddings.

The original text isn’t lost, but generating embeddings can take time and may cost money. There are exceptions when models explicitly share a compatible embedding space, but it’s safest not to assume that.
