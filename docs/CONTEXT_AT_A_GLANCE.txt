THE MESSAGE ARRAY SENT TO LLM:
─────────────────────────────────────────────────────────────────────────────

[
  Message 0: SYSTEM ROLE
  ├─ Base System Prompt
  │  └─ "You are a helpful assistant..."
  │
  └─ Time-Layered Memory Context
     ├─ Raw Notes
     │  └─ Recent notes from the configured rolling-day window
     ├─ Weekly Summaries
     │  └─ Mid-range weekly rollups for completed weeks
     └─ Monthly Summaries
        └─ Older monthly rollups for completed months

  Message 1-20+: USER/ASSISTANT ROLES (conversation history)
  ├─ Message 1: User - Previous session message
  ├─ Message 2: Asst - Response
  ├─ ...
  ├─ Message 20: User - [Current datetime] Your message today
  └─ (grows as you chat)
]

═════════════════════════════════════════════════════════════════════════════

COMPONENT BREAKDOWN:
─────────────────────────────────────────────────────────────────────────────

┌─ 1. BASE SYSTEM PROMPT
│  ├─ Source: Profile prompt files
│  └─ Status: ✅ Always present
│
├─ 2. RAW NOTES
│  ├─ Source: Memory notes table
│  ├─ Window: Configured raw-note days, extended back to Monday
│  └─ Status: 🟢 Recent detailed memory
│
├─ 3. WEEKLY SUMMARIES
│  ├─ Source: memory_summaries table
│  ├─ Window: Configured weekly-summary weeks
│  └─ Status: 🟢 Mid-range compressed history
│
├─ 4. MONTHLY SUMMARIES
│  ├─ Source: memory_summaries table
│  ├─ Window: Configured monthly-summary months or all remaining
│  └─ Status: 🟢 Older compressed history
│
└─ 5. CONVERSATION HISTORY
   ├─ Source: In-memory conversation state
   ├─ Initial: Last 20 messages from previous conversation history
   └─ Status: 🟢 Always included

═════════════════════════════════════════════════════════════════════════════

CACHE IDENTITY SHAPES:
─────────────────────────────────────────────────────────────────────────────

Cache key is based on:
  hash(
    profileID,
    systemPrompt,
    assembled timeline state,
    embeddingModel
  )

Timeline state includes:
  - raw-note settings
  - weekly-summary settings
  - monthly-summary settings
  - included raw note IDs
  - included summary IDs and freshness state

═════════════════════════════════════════════════════════════════════════════

SEARCH TOOLS:
─────────────────────────────────────────────────────────────────────────────

The assistant may call:
- search_memory_keywords
- search_memory_time_range

These are exposed only when the active model supports tool calling.

═════════════════════════════════════════════════════════════════════════════

FOOTER TELEMETRY:
─────────────────────────────────────────────────────────────────────────────

Footer token telemetry now includes:
- total input tokens
- total output tokens
- estimated cost
- context used percentage when model context max is known
- model max context size when available

If model context max is unknown, the footer remains honest and omits the percentage.

═════════════════════════════════════════════════════════════════════════════

KEY TAKEAWAY:
─────────────────────────────────────────────────────────────────────────────

The LLM receives:
1. Instructions (system prompt)
2. Recent detailed memory (raw notes)
3. Mid-range rollups (weekly summaries)
4. Older rollups (monthly summaries)
5. Conversation thread and current datetime
6. On-demand memory search tools when supported

This replaces the old previous-session-summary plus long-term-snippet model.
