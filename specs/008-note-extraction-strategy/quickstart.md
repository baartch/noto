# Quickstart: note-extraction-strategy

## Goal

Validate note extraction, deduplication, and footer notifications end-to-end in a local profile.

## Steps

1. Start the app with a test profile.
2. Run a chat that includes a clear note-worthy fact.
3. Verify the note is stored once and the footer notification appears for ~3 seconds.
4. Repeat the fact with different wording and confirm no duplicate is stored.
5. Ask a related follow-up and confirm relevant notes are retrieved.
